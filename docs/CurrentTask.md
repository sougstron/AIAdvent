# CurrentTask — текущая глобальная задача

Работаем только с одной текущей задачей. Остальной код не трогаем.

## Текущая задача

- **Task 5** — путь: `tree/task-5/`
- Что это: **Model Ladder** — настольное приложение на Tauri. По кнопке
  «Сравнить» один и тот же запрос уходит одновременно на три модели разного
  класса — слабую (`qwen3.8-27b` через yolo), среднюю (`grok-4.6` на xai,
  reasoning medium) и сильную (`anthropic/claude-opus-5` через openrouter,
  reasoning high). Замеряются время ответа, токены и стоимость; ответы вслепую
  оценивает четвёртая модель-судья `hf:moonshotai/Kimi-K3` из synthetic.
  Отдельная проверка доказывает, что три ступени — действительно три разные
  модели. Сделано из дословной копии `tree/task-4/`; результаты, цифры прогона
  и найденные подводные камни — в `tree/task-5/README.md` и `REPORT.md`.
- Состав: `src/` (исходник) + `ui/` (фронт) + `tauri.conf.json`, `capabilities/`,
  `icons/`, `build.rs` + `target/release/ask` и корневой `model-ladder`
  (релизные бинарники, «таргет») + `Cargo.toml`/`Cargo.lock` — всё, что нужно,
  чтобы собрать.
- Собираем оттуда (ни `tauri-cli`, ни npm не нужны — фронт статический):
  ```sh
  cargo build --release --manifest-path tree/task-5/Cargo.toml
  ```
- Все изменения кода вносим только внутри `tree/task-5/`.

## Правила

1. Активна всегда только одна задача — та, что указана в разделе «Текущая задача».
2. Код вне папки текущей задачи (корневой `src/`, другие `tree/task-*`) не менять.
3. Новое состояние приложения закидывается в следующую папку (`tree/task-N/`):
   туда копируются актуальные `src/` и свежий релизный бинарник, и этот файл
   обновляется на новую задачу.
4. В `Cargo.toml` внутри каждой папки есть пустой `[workspace]` — он отцепляет
   снапшот от workspace корня репо, чтобы сборка из папки работала автономно.
   Не удалять.
