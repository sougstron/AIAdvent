# CurrentTask — текущая глобальная задача

Работаем только с одной текущей задачей. Остальной код не трогаем.

## Текущая задача

- **Task 6** — путь: `tree/task-6/`
- Что это: **рабочий агент** — чат-TUI на ratatui поверх z.ai (plain
  `https://api.z.ai/api/paas/v4`). Разговор — сущность `Agent` (настройки,
  история, AGENTS.md в system), а не голый POST. Дефолтная и единственная
  live-модель — `glm-5.3-flash`; остальные id из каталога выбираются, но на
  отправке отказ, потому что они стоят денег и не гонялись. Сессии —
  `~/.ask6/sessions/`. Результаты `--verify`, цифры и подводные камни — в
  `tree/task-6/README.md`.
- Состав: `src/` (исходник) + `Cargo.toml`/`Cargo.lock` — всё, что нужно,
  чтобы собрать. Пустой `[workspace]` отцепляет снапшот от корня репо.
- Собираем оттуда:
  ```sh
  cargo build --release --manifest-path tree/task-6/Cargo.toml
  ```
  Бинарник: `tree/task-6/target/release/ask` (`target/` в gitignore, не коммитить).
- Все изменения кода вносим только внутри `tree/task-6/`.

## Правила

1. Активна всегда только одна задача — та, что указана в разделе «Текущая задача».
2. Код вне папки текущей задачи (корневой `src/`, другие `tree/task-*`) не менять.
3. Новое состояние приложения закидывается в следующую папку (`tree/task-N/`):
   туда копируются актуальные `src/` и свежий релизный бинарник, и этот файл
   обновляется на новую задачу.
4. В `Cargo.toml` внутри каждой папки есть пустой `[workspace]` — он отцепляет
   снапшот от workspace корня репо, чтобы сборка из папки работала автономно.
   Не удалять.
