# CurrentTask — текущая глобальная задача

Работаем только с одной текущей задачей. Остальной код не трогаем.

## Текущая задача

- **Task 11** — путь: `tree/task-11/`
- Что это: рабочий агент, чат-TUI на ratatui поверх z.ai (plain
  `https://api.z.ai/api/paas/v4`), с **управлением контекстом: пять стратегий
  в одном переключателе** — `off` (вся история), `summary` (бегущее summary +
  хвост из N, задача 9), `window` (скользящее окно: только последние N),
  `facts` (key-value память в system + последние N, обновляется отдельным
  вызовом после каждой реплики пользователя) и `branch` (дерево диалога:
  чекпойнты, ветки, своя память на ветку, на проводе только путь активной
  ветки). Переключатель: строка `strategy` в настройках, `/strategy`,
  `--strategy` (`/compress` и `--compress` остались алиасами). Один
  диспетчер `strategy::apply` / `strategy::blocks` решает, что уходит на
  провод и что — в system.
  Доказательства живые и причинные: `ask --verify-compress` (summary) и
  `ask --verify-context window|facts|branch|all`, плюс `--verify-model` для
  прогона на любой модели, которую пропускает денежная гвардия (включая
  OpenRouter `:free`). Все четыре вердикта получены живьём: summary — на
  `glm-5.3-flash`, остальные три — на `nvidia/nemotron-3-super-120b-a12b:free`.
  Дефолтная live-модель — `glm-5.3-flash`; остальные id из каталога
  выбираются, но на отправке отказ, потому что они стоят денег и не
  гонялись. Сессии — `~/.ask6/sessions/` (формат расширен полями `facts` и
  `tree`, файлы прошлых задач читаются и мигрируют в одну ветку `main`).
  Подробности, состав и результаты проверок — в `tree/task-11/README.md`.
- Состав: `src/` (исходник) + `Cargo.toml`/`Cargo.lock` — всё, что нужно,
  чтобы собрать. Пустой `[workspace]` отцепляет снапшот от корня репо.
- Собираем оттуда:
  ```sh
  cargo build --release --manifest-path tree/task-11/Cargo.toml
  ```
  Бинарник: `tree/task-11/target/release/ask` (`target/` в gitignore, кроме
  самого `ask` — см. корневой `.gitignore`).
- Все изменения кода вносим только внутри `tree/task-11/`.

## Правила

1. Активна всегда только одна задача — та, что указана в разделе «Текущая задача».
2. Код вне папки текущей задачи (корневой `src/`, другие `tree/task-*`) не менять.
3. Новое состояние приложения закидывается в следующую папку (`tree/task-N/`):
   туда копируются актуальные `src/` и свежий релизный бинарник, и этот файл
   обновляется на новую задачу.
4. В `Cargo.toml` внутри каждой папки есть пустой `[workspace]` — он отцепляет
   снапшот от workspace корня репо, чтобы сборка из папки работала автономно.
   Не удалять.
