## Текущая задача

- **Task 10** — путь: `tree/task-10/`
- Что это: **заготовка под таску 10** — дословная копия `tree/task-9/`,
  зафиксированная на момент TASK-054. Нового кода пока нет: это рабочий
  агент, чат-TUI на ratatui поверх z.ai (plain `https://api.z.ai/api/paas/v4`),
  с управлением контекстом — сжатие истории (`compress=off|summary`,
  `/compress`, `--compress`; доказательство — `ask --verify-compress`)
  поверх сущности `Agent` (настройки, история, AGENTS.md в system).
  Дефолтная и единственная live-модель — `glm-5.3-flash`; остальные id из
  каталога выбираются, но на отправке отказ, потому что они стоят денег и
  не гонялись. Сессии — `~/.ask6/sessions/`. Подробности, состав и
  результаты `--verify` — в `tree/task-10/README.md` (пока идентичен
  `tree/task-9/README.md`).
- Состав: `src/` (исходник) + `Cargo.toml`/`Cargo.lock` — всё, что нужно,
  чтобы собрать. Пустой `[workspace]` отцепляет снапшот от корня репо.
- Собираем оттуда:
  ```sh
  cargo build --release --manifest-path tree/task-10/Cargo.toml
  ```
  Бинарник: `tree/task-10/target/release/ask` (`target/` в gitignore, кроме
  самого `ask` — см. корневой `.gitignore`).
- Все изменения кода вносим только внутри `tree/task-10/`.

## Правила

1. Активна всегда только одна задача — та, что указана в разделе «Текущая задача».
2. Код вне папки текущей задачи (корневой `src/`, другие `tree/task-*`) не менять.
3. Новое состояние приложения закидывается в следующую папку (`tree/task-N/`):
   туда копируются актуальные `src/` и свежий релизный бинарник, и этот файл
   обновляется на новую задачу.
4. В `Cargo.toml` внутри каждой папки есть пустой `[workspace]` — он отцепляет
   снапшот от workspace корня репо, чтобы сборка из папки работала автономно.
   Не удалять.
