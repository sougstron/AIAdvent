- **Модель разбора:** `glm-5.3`

- **Общее время:** 41.9 с

## Проверка: доезжает ли `temperature` до сэмплера

**✅ параметр применяется** — `openrouter` / `meta-llama/llama-3.3-70b-instruct`

## Разбор (glm-5.3)

## Точность
Все три ответа формально соответствуют инструкции (название + слоган, тема моря и кофе). При temperature = 0 ответ наиболее буквальный: слоган «Пей кофе, смотри на море» почти дословно пересказывает условие задачи. При 1.2 связность проседает: «уходите с удовольствием» — странный призыв для кофейни, смысл уходит в сторону. Ответ при 0.7 держит баланс — выполняет инструкцию без буквализма и без смысловых сбоев.

## Креативность
Рост температуры заметен по метафоричности: «Пей кофе, смотри на море» (0) — пересказ условия; «вдыхаем свободу» (0.7) — первая метафора; «Кофейная гавань» и «Плавайте в аромате» (1.2) — самые образные формулировки. Но при 1.2 креативность уже переходит в шероховатости: «уходите с удовольствием» звучит как артефакт генерации, а не как осознанный ход.

## Разнообразие
Цифры совпадения повторных прогонов говорят сами: 100% при 0 (полностью детерминированный вывод), 18% при 0.7 (почти каждый прогон даёт новый вариант), 10% при 1.2 (максимальная вариативность, стабильности нет вовсе). То есть температура напрямую управляет воспроизводимостью: от копии до уникального ответа на каждый запуск.

## Когда какую температуру брать
- **0** — извлечение данных, классификация, генерация по шаблону, любые задачи, где нужен одинаковый результат при повторных запусках.
- **0.7** — рабочий вариант для нейминга, копирайтинга, слоганов: достаточно вариативности без потери связности. Для данной задачи оптимален.
- **1.2** — брейншторм, генерация большого числа черновых идей с последующим ручным отбором; мириться с риском бессвязных фрагментов вроде «уходите с удовольствием».

## Вывод
Температура задаёт обмен воспроизводимостью и связностью на новизну. Для креативной задачи «название + слоган» разумный выбор — около 0.7; выше — только для черновиков с ручной фильтрацией.
