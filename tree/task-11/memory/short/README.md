Краткосрочная память: текущий диалог. Файл на сессию — `<id сессии>.json`,
новый чат (`Ctrl-N`) начинает новый файл, старый остаётся на диске.

Внутри две разные вещи:

* `records` — выжимка, которую сделал экстрактор (ключи `диалог.`, `тема.`);
  она появляется только при стратегии `memory`;
* `dialog` — **дословная копия всех реплик этой сессии**, она пишется всегда,
  на каждом ходе, независимо от стратегии. Да, это дубликат файла сессии из
  `~/.ask6/sessions/`: краткосрочная память — это и есть «текущий разговор»,
  и проверяться она должна там, где живёт.

Посмотреть копию не выходя из TUI: `/mem dialog`.
