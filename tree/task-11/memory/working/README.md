Рабочая память: данные текущей задачи. Один файл на задачу — `<задача>.json`,
переключается `/mem task <имя>`. Смена задачи убирает этот слой с провода, но
не удаляет файл: данные прошлой задачи лежат рядом и возвращаются вместе с ней.
Ключи по соглашению начинаются с `задача.`, `данные.` или `шаг.`.
