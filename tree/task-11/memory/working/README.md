Рабочая память: данные текущей задачи — вводные, ограничения, сроки,
промежуточные результаты. Файл на задачу: `<имя задачи>.json`, по умолчанию
`default.json`; `/mem task <имя>` переключает задачу, и старый файл остаётся
на месте со всем, что в нём было. Ключи по соглашению начинаются с `задача.`,
`данные.` или `шаг.`.

Файл создаётся пустым при первом же запуске — «в рабочей памяти ничего нет»
должно отличаться от «рабочую память ни разу не открывали». Заполняется он
экстрактором **только при стратегии `memory`** (`ask --strategy memory ...`
или `/strategy memory` в TUI) — либо руками: `/mem working set задача.срок
пятница`.
