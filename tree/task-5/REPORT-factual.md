## Разбор (glm-5.3)

## Точность
Все три ответа выдержали формат «ровно 3 предложения», но по фактике различаются заметно. Вариант с 0 точен и лаконичен: корректное определение, без добавлений — при 100% воспроизводимости это эталон. Вариант с 0.7 также точен и даже информативнее за счёт корректной оговорки про ошибки при высокой температуре. Вариант с 1.2 содержит два дефекта: артефакт генерации «влияет наgeneration текста» и фактически неверное утверждение, что «температура обычно устанавливается в диапазоне от 0 до 1» и что «1 соответствует полностью случайному тексту» — сам этот запуск шёл с T=1.2, а T=1 означает сэмплирование из неизменённого распределения, а не равновероятный выбор токенов.

## Креативность
При 0 формулировки шаблонные и нейтральные: «контролирует уровень случайности», «баланс между креативностью и связностью». При 0.7 появляется вариативность в подаче: «разнообразие и непредсказуемость», «с большей вероятностью ошибок и бессмысленных фрагментов» — ответ переформулирует одно и то же другими словами. При 1.2 модель пытается добавить новый контент («спонтанность», числовой диапазон «от 0 до 1»), то есть креативность выше, но её качество падает — вплоть до склейки латинского токена с русским словом («наgeneration»).

## Разнообразие
Ключевая метрика — совпадение повторных прогонов: при T=0 оно 100% (детерминированный вывод), при 0.7 и 1.2 — одинаково низкие 27%, то есть по разбросу между запусками эти две настройки в данном эксперименте не различаются. Доля уникальных слов внутри ответа (84% / 73% / 79%) — слабый сигнал: у 0.7 она ниже просто из-за повторов «генерирует», «температуре», «разнообразный». Разница между 0.7 и 1.2 проявилась не в разнообразии, а в качестве: артефакты и фактическая ошибка появились только на 1.2.

## Когда какую температуру брать
- **0** — фактология, классификация, извлечение данных, код, строгий формат, когда нужна воспроизводимость ответа.
- **0.7** — рабочий баланс для диалогов и обычных текстов: вариативность формулировок без потери точности.
- **1.2** — брейншторм, черновики идей, художественные наброски, где допустимы ошибки и обязателен вычитывание результата.
